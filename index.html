QuickCut Privacy Policy

Developer: Mirens Studio
Application: QuickCut
Package: com.mirens.quickcut
Last updated: August 7, 2026

1. Overview

QuickCut is a video editing utility designed to process media locally on the user's Android device.

QuickCut does not require an account and does not automatically upload the user's videos, audio files, file names, file locations, or editing projects to Mirens Studio servers.

2. Data collection

The current version of QuickCut does not collect personal data from users and does not transmit user data to Mirens Studio servers.

QuickCut does not currently use advertising services or analytics services that collect user data on behalf of Mirens Studio.

3. Media files and device storage

QuickCut accesses media only when the user chooses a file for editing or performs another explicit action that requires access to that media.

Selected media is processed locally on the device. QuickCut uses the selected media only to provide requested functions such as previewing, trimming, cropping, audio extraction, and saving an edited result.

Exported files are saved to the user's device at the user's request. Mirens Studio does not receive copies of those files.

4. Data sharing

QuickCut does not automatically share user data with Mirens Studio, advertisers, analytics providers, data brokers, or other companies and organizations.

5. Support and email

QuickCut includes options that can open the user's chosen email application with a prepared support message.

The application does not send the message automatically. The user can review, change, or delete its contents before choosing whether to send it.

A prepared support message may contain basic technical information such as the QuickCut version, build type, Android version, device model, and application language. QuickCut does not automatically attach videos, media file names, file URIs, or application logs.

If the user chooses to send an email or manually attach a file, that information is transmitted through the user's selected email provider and is also subject to that provider's privacy practices.

6. Data retention and deletion

Because QuickCut does not maintain user accounts or upload editing data to Mirens Studio servers, Mirens Studio does not maintain a server-side account or editing-data archive for QuickCut users.

Original and exported media files remain under the user's control on the device and can be removed by the user using QuickCut, Android, or another file or media management application where applicable.

If a user voluntarily contacts Mirens Studio by email, the resulting correspondence may be retained as reasonably necessary to respond to the request, resolve a support issue, or maintain a record of the communication. A user may request deletion of such correspondence by contacting the privacy address below.

7. Security

QuickCut is designed to minimize transmission of user data by performing its core media-processing functions locally on the device.

No method of electronic storage or communication can be guaranteed to be completely secure. Users should avoid sending personal or sensitive media through support email unless it is necessary for their support request.

8. Third-party services

QuickCut may rely on Android system components and libraries required for application operation and media processing. The current release does not use third-party advertising or user analytics services for Mirens Studio.

When a user deliberately leaves QuickCut and uses another application, such as an email client, that application's own privacy policy and terms apply.

9. Changes to this Privacy Policy

This Privacy Policy may be updated if QuickCut's functionality or data practices change. The updated policy will be published on this page and the "Last updated" date will be changed accordingly.

10. Contact

For privacy questions, requests, or concerns regarding QuickCut, contact:

Mirens Studio
Email: support.quickcut@gmail.com

Политика конфиденциальности QuickCut

Разработчик: Mirens Studio
Приложение: QuickCut
Пакет: com.mirens.quickcut
Последнее обновление: 7 августа 2026 г.

1. Общая информация

QuickCut — инструмент для редактирования видео, предназначенный для обработки медиафайлов локально на Android-устройстве пользователя.

QuickCut не требует создания аккаунта и не загружает автоматически видео, аудиофайлы, имена файлов, расположение файлов или проекты редактирования на серверы Mirens Studio.

2. Сбор данных

Текущая версия QuickCut не собирает персональные данные пользователей и не передает пользовательские данные на серверы Mirens Studio.

В текущей версии QuickCut отсутствуют рекламные и аналитические сервисы, собирающие пользовательские данные от имени Mirens Studio.

3. Медиафайлы и хранилище устройства

QuickCut получает доступ к медиафайлу только после того, как пользователь сам выбирает его для редактирования или выполняет другое явное действие, требующее доступа к этому файлу.

Выбранные медиафайлы обрабатываются локально на устройстве и используются только для запрошенных пользователем функций, включая просмотр, обрезку, кадрирование, извлечение аудио и сохранение результата.

Результаты сохраняются на устройстве по запросу пользователя. Mirens Studio не получает копии этих файлов.

4. Передача данных третьим сторонам

QuickCut автоматически не передает пользовательские данные Mirens Studio, рекламным компаниям, аналитическим сервисам, брокерам данных или другим компаниям и организациям.

5. Поддержка по электронной почте

В QuickCut имеются функции, которые могут открыть выбранное пользователем почтовое приложение и подготовить черновик обращения в поддержку.

QuickCut не отправляет такое письмо автоматически. Перед отправкой пользователь может просмотреть, изменить или удалить его содержимое.

Подготовленный текст может содержать базовую техническую информацию: версию QuickCut, тип сборки, версию Android, модель устройства и язык приложения. Видео, имена файлов, URI файлов и журналы приложения автоматически к письму не прикладываются.

Если пользователь самостоятельно отправляет письмо или добавляет вложение, данные передаются через выбранный им почтовый сервис, к которому также применяются правила конфиденциальности этого сервиса.

6. Хранение и удаление данных

Поскольку QuickCut не создает учетные записи пользователей и не загружает данные редактирования на серверы Mirens Studio, у Mirens Studio отсутствует серверный архив аккаунта или проектов пользователя QuickCut.

Исходные и сохраненные медиафайлы остаются под контролем пользователя на его устройстве и могут быть удалены пользователем средствами QuickCut, Android или другого приложения для управления файлами и медиа, где это применимо.

Если пользователь добровольно обращается в Mirens Studio по электронной почте, переписка может храниться столько, сколько разумно необходимо для ответа, решения вопроса поддержки или сохранения истории обращения. Пользователь может запросить удаление такой переписки по адресу, указанному ниже.

7. Безопасность

QuickCut спроектирован так, чтобы минимизировать передачу пользовательских данных: основные функции обработки медиа выполняются локально на устройстве.

Ни один способ электронного хранения или передачи информации нельзя гарантировать как абсолютно безопасный. Не рекомендуется отправлять личные или конфиденциальные медиафайлы в поддержку без необходимости.

8. Сторонние сервисы

Для работы приложения и обработки медиа QuickCut может использовать системные компоненты Android и программные библиотеки. Текущий релиз не использует сторонние рекламные или пользовательские аналитические сервисы от имени Mirens Studio.

Если пользователь намеренно покидает QuickCut и использует другое приложение, например почтовый клиент, к нему применяются собственные условия и политика конфиденциальности этого приложения.

9. Изменения политики

Эта политика может обновляться при изменении функций QuickCut или порядка обработки данных. Новая версия будет опубликована на этой странице, а дата последнего обновления будет изменена.
